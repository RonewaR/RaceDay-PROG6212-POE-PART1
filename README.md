# RaceDay System - PROG6212 POE Part 1

## System Description

RaceDay is a race event management system designed to allow organisers to manage race events and participants to register for race categories, make payments and view their results.

## User Roles

### Organiser
The Organiser can:
- Create and manage race events
- Create and manage race categories
- View participant enrolments
- Capture and update race results

### Participant
The Participant can:
- Register and log in
- Browse available race events
- Enrol in race categories
- Make payments
- View personal results

## Project Documentation

The `/docs` folder contains:

- ERD image
- API Endpoint Plan
- SQL database script
